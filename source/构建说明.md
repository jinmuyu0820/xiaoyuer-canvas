# 源码

GitHub 仓库里这个目录就是主体；运行包（`.output`、`runtime`、`SnowLeopard Vision`、空的 `data`）在 Releases 中提供。

在整合包里，日常使用不需要这个目录，删掉也不影响 `启动画布.cmd`。

这里保留的是画布的可读源码和构建配置，方便以后改界面/功能：

- `src/`：应用源码（已去掉测试文件）
- `messages/`：中/英/日文案
- `public/`：静态资源
- `drizzle/`：SQLite 迁移
- `scripts/`：构建、数据库初始化、i18n 检查脚本
- `package.json`、`vite.config.ts`、`tsconfig.json` 等构建配置

重新构建需要 Node.js 22+ 和 pnpm：

```powershell
cd source
pnpm install
pnpm build
```

发布版要带界面名「小鱼儿画布整合包」，构建时加环境变量；不加则保持默认 BeatDesign：

```powershell
$env:VITE_APP_NAME='小鱼儿画布整合包'
pnpm build
Remove-Item Env:VITE_APP_NAME
```

构建完成后，把 `source\.output` 覆盖到上一层的 `.output`，再双击 `启动画布.cmd`。构建前先关闭正在运行的画布。

源码里不包含 `node_modules`、`.pnpm-store`、测试、QA 脚本和旧的本地数据。
